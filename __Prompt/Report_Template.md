## 4. 상세 발견 사항

### Critical Findings

#### Finding #1
**Severity:** CRITICAL
**Category:** Security
**Location:** `src/auth/login.py:42`

**Issue:**
SQL 인젝션 취약점 발견. 사용자 입력이 검증 없이 직접 SQL 쿼리에 삽입됨.

**Impact:**
- 데이터베이스 전체 노출 위험
- 사용자 정보 탈취 가능
- 데이터 삭제/변조 가능

**Recommendation:**
파라미터화된 쿼리 또는 ORM 사용

**Code Example:**
```python
# Before (취약)
query = f"SELECT * FROM users WHERE id = '{user_input}'"

# After (안전)
query = "SELECT * FROM users WHERE id = %s"
cursor.execute(query, (user_input,))
```
